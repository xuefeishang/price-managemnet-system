## 表结构详情

### sys_user - 系统用户表

**说明**：存储系统用户信息，支持三种角色（管理员、编辑者、查看者）

| 字段名 | 数据类型 | 约束 | 默认值 | 说明 |
|--------|----------|------|--------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | - | 用户ID |
| username | VARCHAR(50) | NOT NULL, UNIQUE | - | 用户名 |
| password | VARCHAR(200) | NOT NULL | - | 密码（BCrypt加密） |
| role | VARCHAR(20) | NOT NULL | - | 角色：ADMIN/EDITOR/VIEWER |
| status | VARCHAR(20) | NOT NULL | 'ACTIVE' | 状态：ACTIVE/INACTIVE |
| nickname | VARCHAR(50) | - | - | 昵称 |
| email | VARCHAR(100) | - | - | 邮箱 |
| phone | VARCHAR(20) | - | - | 电话 |
| last_login_time | DATETIME | - | NULL | 最近登录时间 |
| last_login_ip | VARCHAR(50) | - | NULL | 最近登录 IP |
| login_count | INT | - | 0 | 登录次数 |
| password_updated_time | DATETIME | - | NULL | 密码更新时间 |
| is_locked | BOOLEAN | - | FALSE | 是否锁定 |
| locked_time | DATETIME | - | NULL | 锁定时间 |
| created_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_time | DATETIME | - | CURRENT_TIMESTAMP ON UPDATE | 更新时间 |

**索引**：
- `idx_user_username` (username)
- `idx_user_status` (status)
- `idx_user_role` (role)

**枚举值**：

`role` 字段：
| 值 | 说明 |
|----|------|
| ADMIN | 管理员 - 拥有所有权限 |
| EDITOR | 编辑者 - 可编辑产品和价格 |
| VIEWER | 查看者 - 仅可查看数据 |

`status` 字段：
| 值 | 说明 |
|----|------|
| ACTIVE | 启用状态 |
| INACTIVE | 禁用状态 |

### price - 价格表

**说明**：存储产品价格信息，支持价格有效期管理

| 字段名 | 数据类型 | 约束 | 默认值 | 说明 |
|--------|----------|------|--------|------|
| id | BIGINT | PRIMARY KEY, AUTO_INCREMENT | - | 价格ID |
| product_id | BIGINT | NOT NULL, FOREIGN KEY | - | 产品ID |
| original_price | DECIMAL(15,4) | - | - | 原价 |
| current_price | DECIMAL(15,4) | NOT NULL | - | 现价 |
| cost_price | DECIMAL(15,4) | - | - | 成本价 |
| effective_date | DATE | - | - | 生效日期 |
| expiry_date | DATE | - | - | 失效日期 |
| unit | VARCHAR(50) | - | - | 单位：元/吨、元/克等 |
| price_spec | VARCHAR(200) | - | - | 价格规格 |
| created_by | BIGINT | - | - | 创建人 |
| created_time | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

**外键**：
- `product_id` → `product(id)` ON DELETE CASCADE ON UPDATE CASCADE

**索引**：
- `idx_price_product` (product_id)
- `idx_price_effective` (effective_date, expiry_date)
- `idx_price_created` (created_time)

**业务规则**：
- 同一产品的价格按生效日期分段有效
- 新价格生效时，旧价格自动设置失效日期

#### notification_message / notification_recipient / notification_delivery_log / notification_outbox / notification_preference / notification_channel_config - 通知表

**说明**：通知采用“消息、接收人、渠道投递日志、Outbox、用户偏好、小程序订阅授权、订阅资格查询快照、渠道运行配置”结构。业务模块统一通过 `NotificationCreateCommand` 接入消息，不直接写 `notification_*` 表。业务事件在主事务提交后通过独立事务创建通知，避免通知失败回滚核心业务。站内通知默认可用且不可关闭，外部渠道先写投递日志和 Outbox，由 worker 异步处理；Provider 未配置或用户关闭偏好时记录为 SKIPPED，不影响业务事务。延迟投递到期前会重新读取用户偏好，并检查消息是否过期、收件记录是否归档；不可继续投递时记录为 SKIPPED。小程序订阅消息由 `MINI_PROGRAM` Provider 使用 `sys_user.wechat_openid`、运行配置和授权次数发送，未绑定、未授权或模板未配置时记录为 SKIPPED，站内消息继续兜底。`notification_mini_program_eligibility` 仅用于管理端状态筛选和分页，不参与真实投递资格判断。

主要字段：

- `notification_message`：`type`、`title`、`summary`、`content`、`business_type`、`business_id`、`channels`、`priority`、`link_type`、`link_params`、`dedupe_key`、`expire_time`、`event_count`、`created_by`、`created_time`；`event_count BIGINT NOT NULL DEFAULT 1` 记录聚合消息包含的真实业务事件数量
- `notification_recipient`：`message_id`、`user_id`、`read_status`、`read_time`、`archived`、`archived_time`、`first_seen_time`
- `notification_delivery_log`：`message_id`、`recipient_id`、`user_id`、`channel`、`status`、`provider`、`retry_count`、`delivered_time`、`error_code`、`error_message`、`is_test`；测试投递不进入站内列表、不参与聚合和用户偏好延迟，但会真实调用外部渠道
- `notification_outbox`：`event_type`、`aggregate_type`、`aggregate_id`、`payload_json`、`status`、`retry_count`、`next_retry_time`、`locked_by`、`lock_until`、`last_error_code`、`last_error_message`
- `notification_preference`：`user_id`、`notification_type`、`channel`、`enabled`、`quiet_start_time`、`quiet_end_time`、`version`
- `notification_mini_program_subscription`：`user_id`、`openid`、`notification_type`、`template_id`、`status`、`available_count`、`last_authorized_time`、`source`、`created_time`、`updated_time`
- `notification_mini_program_eligibility`：`user_id`、`row_status`、`openid_bound`、`configured_template_count`、`authorized_template_count`、`available_total`、`last_authorized_time`、`config_fingerprint`、`version`、`created_time`、`updated_time`；授权更新、额度消费、用户创建/更新提交后通过事件刷新，模板配置变化和每日校准执行全量重建
- `notification_mini_program_resolution`：`user_id`、`resolve_status`、`resolve_remark`、`remind_after`、`follow_up_required`、`resolved_by`、`resolved_time`、`version`、`created_time`、`updated_time`；按用户保存异常处理、暂不提醒和跟进状态，未绑定 OpenID 的用户也可处理；`version` 防止并发处理互相覆盖
- `notification_channel_config`：`channel`、`enabled`、`app_id`、`endpoint_url`、`secret_cipher`、`secret_key_version`、`secret_fingerprint`、`timeout_ms`、`default_page`、`config_json`、`created_by`、`updated_by`、`version`；AppSecret 等敏感配置只保存密文和指纹，前端不回显明文

关键索引与约束：

- `notification_message.uk_notification_dedupe_key`：同一幂等键只生成一条消息。
- `notification_recipient.uk_notification_message_user`：同一消息同一用户只生成一条接收记录。
- `notification_recipient.idx_notification_recipient_user_time`：支撑我的通知列表按用户倒序分页。
- `notification_outbox.uk_notification_outbox_aggregate`：同一聚合对象只生成一条 Outbox，当前用于保证同一投递记录只入队一次。
- `notification_outbox.idx_notification_outbox_status_retry`：支撑 worker 查询可处理任务。
- `notification_preference.uk_notification_preference_user_type_channel`：同一用户、类型、渠道只保留一条偏好。
- `notification_mini_program_subscription.uk_notification_mini_sub_user_type_template`：同一用户、通知类型、模板只保留一条授权记录。
- `notification_mini_program_eligibility.uk_notification_mini_eligibility_user`：同一用户只保留一条资格查询快照；`idx_notification_mini_eligibility_status_user` 支撑聚合行状态数据库分页。
- `notification_mini_program_resolution.uk_notification_mini_resolution_user`：同一用户只保留一条当前异常处理记录。
- `notification_channel_config.uk_notification_channel_config_channel`：同一通知渠道只保留一条运行配置。

| status | VARCHAR(20) | NOT NULL | DRAFT | 公告状态，取值来自 `system_notice_status` |
| scheduled_publish_time | DATETIME | - | NULL | 计划发布时间 |
| published_time | DATETIME | - | NULL | 实际发布时间 |

| expire_time | DATETIME | - | NULL | 过期时间 |

#### sys_scheduled_task / sys_scheduled_task_log - 通用定时任务表

**说明**：管理多种系统定时任务。价格自动发布任务编码为 `PRICE_AUTO_PUBLISH`，默认停用。

`sys_scheduled_task` 关键字段：

| 字段名 | 数据类型 | 说明 |
|--------|----------|------|

### A. 数据类型说明

| 类型 | 说明 |
|------|------|
| BIGINT | 64位整数，用于ID字段 |
| VARCHAR(n) | 变长字符串，最大n个字符 |
| DECIMAL(p,s) | 定点数，p为总位数，s为小数位数 |
| DATETIME | 日期时间类型 |
| DATE | 日期类型 |
| TEXT | 长文本类型 |
| BOOLEAN | 布尔类型 |

### B. 约束类型说明

| 类型 | 说明 |
|------|------|
| PRIMARY KEY | 主键约束，唯一且非空 |
| NOT NULL | 非空约束 |
| UNIQUE | 唯一约束 |
| FOREIGN KEY | 外键约束 |
| DEFAULT | 默认值约束 |

### C. 索引说明

索引用于加速查询，合理的索引设计可以显著提升查询性能。
系统中的索引设计遵循以下原则：
- 外键字段建立索引加速关联查询
- 经常查询的字段建立索引
- 唯一字段建立唯一索引
- 排序字段建立索引加速排序
