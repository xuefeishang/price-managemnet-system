# 价格展示与管理系统 - 项目完成总结

## 项目概述

本项目是一个前后端分离的价格展示与管理系统，主要面向制造业企业内部员工使用。

> 技术栈详见 [README.md](README.md)

## 已完成的功能

### 1. 用户认证与权限管理
- JWT Token 认证（Access Token + Refresh Token 双 Token 机制）
- 三种角色：管理员（ADMIN）、编辑者（EDITOR）、查看者（VIEWER）
- Token 自动刷新（7天 Refresh Token 有效期）
- API 限流保护（登录 5次/分钟/IP）
- **动态权限系统**（31个权限码，登录时获取用户权限列表）
- 前端权限判断改为动态读取（usePermission.ts）

### 2. 部门管理（新增）
- 树状组织架构（总部/子公司/部门三级）
- 拖拽调整部门层级
- 部门用户统计
- 部门负责人设置
- 用户关联部门（用户表添加 dept_id）

### 3. 产品与价格管理（核心功能）
- 产品分类管理
- 产品 CRUD + 价格管理
- 价格历史记录追踪 + ECharts 可视化
- **首页驾驶舱布局**（经营摘要、核心指标、趋势分析、价格预警）
- 产品列表/价格维护新增产地列
- **分类视觉系统**（分类筛选、分类颜色、分类图标、光晕效果）

### 3. Excel导入导出
- 产品数据批量导入/导出

### 4. 响应式设计
- PC端布局（≥1024px）+ 移动端布局（<1024px）

### 5. 操作日志管理（仅管理员）
- 日志列表查询与筛选
- 统计分析（趋势图、饼图、柱状图）
- 月度报表、年度报表 + 用户排行

### 6. 审批流程管理
- 审批工作流配置（创建、编辑、删除、激活/停用）
- 审批节点配置（节点类型、审批角色、顺序）
- 审批请求管理（待审批、我的申请）

### 7. 字典管理
- 数据字典 CRUD（按分类管理，启用/停用）
- 前端字典服务（useDict composable，全局缓存）
- 所有页面硬编码标签动态化
- **受保护分类隔离**（样式配置分类默认隐藏，仅可查看）
- **"显示系统配置"开关**（ADMIN可查看受保护分类）
- **跳转样式设置入口**（受保护分类提示区域提供跳转按钮）
- **extraValue智能渲染**（根据分类元数据渲染：颜色色块、图标预览、JSON格式化+复制按钮、只读文本）

### 8. 全局样式管理（仅管理员）
- 系统名称自定义
- **Logo Base64 存储**（跨平台兼容，无文件路径问题）
- **色彩方案切换**（7套预设：青绿经典、经典红绿、美股绿红、商务蓝橙、高贵紫金、深矿蓝、暖色系）
- **布局方案切换**（4套预设：经典顶部导航、左侧导航、深矿蓝仪表盘、极简卡片式）
- **字号预设切换**（紧凑、标准、大字体、特大字体）
- 字体配置（标题/正文/数字字体）
- **CSS 变量动态应用**（导航背景、页面背景、卡片圆角等）
- **样式设置与字典管理分离**（专用表 sys_style_config、sys_style_preset）
- **版本快照与回滚**（保存自动生成版本，支持手动回滚历史配置）

### 9. 安全加固
- 敏感配置环境变量化
- CORS 动态配置
- 数据库迁移管理（Flyway）

### 10. 告警系统
- 钉钉/企业微信告警
- 健康检查监听（内存、CPU 阈值）

### 11. AI 智能助手
详见 [plan/ai-agent-design.md](plan/ai-agent-design.md)

### 12. 多端支持（uni-app）
- H5 端支持
- 微信小程序端支持
- APP 端支持（iOS/Android）
- 微信一键登录
- 首页价格概览（日期选择、分类筛选、重点关注指标、产品列表）
- 详情页价格走势图（30/180/365天切换）
- 产品规格显示
- 价格差异显示（涨跌标签）
- 分类筛选功能（横向滚动+指示箭头）
- 详见 [plan/multi-platform-adaptation.md](plan/multi-platform-adaptation.md)
