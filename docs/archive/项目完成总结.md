# 价格展示与管理系统 - 项目完成总结

## 项目概述

本项目是一个前后端分离的价格展示与管理系统，主要面向制造业企业内部员工使用。

> 技术栈详见 [README.md](README.md)

## 已完成的功能

### 1. 用户认证与权限管理
- JWT Token 认证（Access Token + Refresh Token 双 Token 机制）
- 三种角色：管理员（ADMIN）、编辑者（EDITOR）、查看者（VIEWER）
- Token 自动刷新（7天 Refresh Token 有效期）
- API 限流保护（登录 5次/分钟/IP）
- **动态权限系统**（32个权限码，登录/刷新资料时获取用户权限列表）
- 前端权限判断改为动态读取（usePermission.ts）
- 管理员用户管理支持独立多角色分配，编辑用户资料时可设置新密码且不混入角色选择
- **个人中心与账号运维**：资料维护、密码修改、账号安全信息、登录历史、会话管理、我的操作记录和个人偏好；修改密码会撤销全部 Refresh Token 并要求重新登录
- **外部 API Key 授权管理第一阶段**：独立 `/api/external/v1/**` 外部接口、HMAC-SHA256 签名、Nonce 防重放、IP 白名单、分钟限流、日限额、调用日志和密钥管理页面；新增运行时服务开关、接口参数 schema 与 Node.js / PowerShell / curl 可复制调用示例；默认关闭，不影响内部 JWT 功能

### 2. 部门管理（新增）
- 树状组织架构（总部/子公司/部门三级）
- 拖拽调整部门层级
- 部门用户统计
- 部门负责人设置
- 用户关联部门（用户表添加 dept_id）

### 3. 产品与价格管理（核心功能）
- 产品分类管理
- 产品 CRUD + 价格管理
- 价格历史记录追踪 + ECharts 可视化
- **首页驾驶舱布局**（经营摘要、核心指标、重点走势、价格预警；区块显隐和排序跟随样式设置）
- **浏览器最小化兼容**（首页图表在窗口最小化/页面隐藏时暂停自动 resize，路由层屏蔽 Vue Router 隐藏态滚动保存导致的窗口恢复）
- **首页产品列表排序与分页表格**（按当前启用分类/产品顺序展示，PC端支持分页表格、搜索、分类筛选、排序和主曲线联动）
- **日常价格查询页**（VIEWER 可访问，只读分页查询每日价格，支持条件筛选、产品名称内嵌产地胶囊与规格、“较昨日”列、右侧 Home 风格趋势摘要和按当前筛选条件导出）
- 产品列表/价格维护新增产地列；首页产品卡片、重点走势和样式设置预览在存在产地时展示产地信息
- 价格维护支持保存草稿与发布分离，发布后才写入正式价格并生成站内通知；PC 侧边栏用户卡片更多菜单提供消息入口，未读时三点按钮切换为红色数字角标，通知抽屉支持未读筛选、全部已读、结构化跳转和带抖动/退避的未读数刷新；系统管理新增通用定时任务页面，价格自动发布任务默认停用并支持后续启用
- **分类视觉预设系统**（整套组合方案 + 1组自定义组合 + 分组方案库，按产品分类配置 icon、主色、浅底、边框、光晕与趋势图色）

### 3. Excel导入导出
- 产品数据批量导入/导出
- 日常价格查询数据导出，导出字段与页面可见字段一致

### 4. 响应式设计
- PC端布局（≥1024px）+ 移动端布局（<1024px）

### 5. 操作日志管理（仅管理员）
- 日志列表查询与筛选
- 统计分析（趋势图、饼图、柱状图）
- 月度报表、年度报表 + 用户排行

### 6. 审批流程管理
- 审批工作流配置（创建、编辑、删除、激活/停用）
- 审批节点配置（节点类型、审批角色、顺序）
- 审批请求管理（待审批、我的申请）

### 7. 字典管理
- 数据字典 CRUD（按领域分组导航管理分类，启用/停用）
- 前端字典服务（useDict composable，全局缓存）
- 所有页面硬编码标签动态化
- **分类说明与效果展示工作台**：PC 端左侧为领域/分类分组导航，中间维护当前分类表格，右侧展示用途、使用页面、字段规则、风险提示和效果预览；移动端提供单个分类选择器、说明摘要和可折叠预览
- **受保护分类隔离**（样式配置分类默认隐藏，仅可查看）
- **"显示系统配置"开关**（ADMIN可查看受保护分类）
- **跳转样式设置入口**（受保护分类提示区域提供跳转按钮）
- **extraValue智能渲染**（根据分类元数据渲染：颜色色块、图标预览、JSON格式化+复制按钮、只读文本）

### 8. 全局样式管理（仅管理员）
- 系统名称与登录页副标题自定义
- **Logo Base64 存储**（跨平台兼容，无文件路径问题）
- **浏览器页签 Logo 动态更新**（优先使用导航栏 Logo，并生成 64×64 页签图标）
- **色彩方案切换**（预设名称由接口返回，前端不硬编码显示名）
- **布局方案切换**（预设名称由接口返回，支持后端扩展）
- **字号预设切换**（紧凑/标准/大字体/特大字体采用可读性重平衡刻度，预设名称由接口返回，支持后端扩展）
- 字体配置（标题/正文/数字字体）
- **CSS 变量动态应用**（导航背景、页面背景、卡片圆角等）
- **样式设置与字典管理分离**（专用表 sys_style_config、sys_style_preset）
- **分类视觉方案库**（5套整体组合方案 + 1组“我的组合” + 5组50套专业预设，普通用户选择方案，管理员使用微调助手）
- **首页体验与首页排序配置**（首页体验保留产品卡片列数、重点产品数量、产品列表模式/每页条数；首页排序统一控制组件显隐与顺序、产品列表分类顺序和分类内产品顺序，重点关注指标与重点走势跟随同源排序，并展示真实产品规格/产地信息）
- **版本快照与回滚**（保存自动生成版本，支持手动回滚历史配置，版本对比覆盖登录页副标题等文本差异）

### 9. 安全加固
- 敏感配置环境变量化
- CORS 动态配置
- 数据库迁移管理（Flyway）

### 10. 告警系统
- 钉钉/企业微信告警
- 健康检查监听（内存、CPU 阈值）

### 12. 多端支持（uni-app）
- H5 端支持
- 微信小程序端支持
- APP 端支持（iOS/Android）
- 微信一键登录
- 小程序角色化导航：VIEWER 展示“首页 / 历史 / 我的”，ADMIN/EDITOR 增加“录入”
- 首页价格概览（日期选择、重点产品价格、主价格曲线、分页产品表格、价格预警）
- 历史价格查询页（只读日期查询、产品搜索、分类筛选、当日售价、昨日售价、较昨日和月均价展示）
- 轻量价格录入页（仅 ADMIN/EDITOR 可见，支持日期、搜索、分类筛选、录入进度、变更保存，并保留昨日售价、价格变化、月均价对照）
- 产品、分类、产地、客户、审批、字典、用户等完整运维保留在 PC 端
- 详情页价格走势图（30/180/365天切换）
- 产品规格显示
- 价格差异显示（涨跌标签）
- 分类筛选功能（横向滚动+指示箭头）
