#### 3.1.3 CORS 配置收紧

**问题：** `AllowedOriginPatterns: ["*"]` 允许所有域名跨域访问。

**实施方案：**

```java
// SecurityConfig.java 修改
@Bean
public CorsConfigurationSource corsConfigurationSource() {
    CorsConfiguration configuration = new CorsConfiguration();
    
    // 修改前：
    // configuration.setAllowedOriginPatterns(Arrays.asList("*"));
    
    // 修改后：
    List<String> allowedOrigins = new ArrayList<>();
    
    // 开发环境
    if (isDevelopment()) {
        allowedOrigins.add("http://localhost:5173");
        allowedOrigins.add("http://127.0.0.1:5173");
    }
    
    // 生产环境
    if (isProduction()) {
        allowedOrigins.add("https://your-production-domain.com");
        allowedOrigins.add("https://www.your-production-domain.com");
    }
    
    configuration.setAllowedOrigins(allowedOrigins);
    configuration.setAllowedMethods(Arrays.asList("GET", "POST", "PUT", "DELETE", "OPTIONS"));
    configuration.setAllowedHeaders(Arrays.asList("*"));
    configuration.setAllowCredentials(true);
    configuration.setMaxAge(3600L);
    
    UrlBasedCorsConfigurationSource source = new UrlBasedCorsConfigurationSource();
    source.registerCorsConfiguration("/**", configuration);
    return source;
}

private boolean isDevelopment() {
    String env = System.getProperty("spring.profiles.active", "dev");
    return "dev".equals(env) || "test".equals(env);
}

private boolean isProduction() {
    String env = System.getProperty("spring.profiles.active", "dev");
    return "prod".equals(env) || "production".equals(env);
}
```

#### 3.2.1 Redis 哨兵模式

**问题：** Redis 单点故障会导致用户无法登录。

**架构设计：**

```
                    ┌─────────────┐
                    │  Redis 哨兵 │
                    │  (Sentinel) │
                    └──────┬──────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
   ┌────▼────┐        ┌────▼────┐        ┌────▼────┐
   │ Redis-1 │        │ Redis-2 │        │ Redis-3 │
   │ Master  │        │ Slave   │        │ Slave   │
   └─────────┘        └─────────┘        └─────────┘
      6379               6380               6381
```

**实施步骤：**

**步骤1：配置 Redis 主从复制**

```bash
# Redis-1 (Master) - redis-master.conf
port 6379
bind 0.0.0.0
requirepass 123abc
masterauth 123abc
appendonly yes
appendfsync everysec
save 900 1
save 300 10
save 60 10000

# Redis-2 (Slave) - redis-slave-1.conf
port 6380
bind 0.0.0.0
requirepass 123abc
masterauth 123abc
replicaof 10.7.5.175 6379
replica-read-only yes

# Redis-3 (Slave) - redis-slave-2.conf
port 6381
bind 0.0.0.0
requirepass 123abc
masterauth 123abc
replicaof 10.7.5.175 6379
replica-read-only yes
```

**步骤2：配置 Sentinel**

```bash
# sentinel.conf
port 26379
bind 0.0.0.0
sentinel monitor mymaster 10.7.5.175 6379 2
sentinel auth-pass mymaster 123abc
sentinel down-after-milliseconds mymaster 5000
sentinel parallel-syncs mymaster 1
sentinel failover-timeout mymaster 10000
sentinel deny-scripts-reconfig yes
```

**步骤3：更新应用配置**

**步骤4：配置读写分离**

```java
// application.yml
spring:
  datasource:
    master:
      url: jdbc:mysql://10.7.5.175:3306/price_management
      username: root
      password: ${DB_PASSWORD}
    slave:
      - url: jdbc:mysql://10.7.5.176:3306/price_management
        username: root
        password: ${DB_PASSWORD}
      - url: jdbc:mysql://10.7.5.177:3306/price_management
        username: root
        password: ${DB_PASSWORD}

// DynamicDataSourceConfig.java
@Configuration
public class DynamicDataSourceConfig {
    
    @Bean
    @Primary
    public DataSource dataSource(
            @Value("${spring.datasource.master.url}") String masterUrl,
            @Value("${spring.datasource.master.username}") String masterUsername,
            @Value("${spring.datasource.master.password}") String masterPassword,
            @Value("${spring.datasource.slave}") List<Map<String, String>> slaves) {
        
        Map<Object, Object> targetDataSources = new HashMap<>();
        
        // Master 数据源
        HikariDataSource masterDataSource = createDataSource(masterUrl, masterUsername, masterPassword);
        targetDataSources.put("master", masterDataSource);
        
        // Slave 数据源
        for (int i = 0; i < slaves.size(); i++) {
            Map<String, String> slave = slaves.get(i);
            HikariDataSource slaveDataSource = createDataSource(
                slave.get("url"), slave.get("username"), slave.get("password"));
            targetDataSources.put("slave-" + i, slaveDataSource);
        }
        
        DynamicDataSource dynamicDataSource = new DynamicDataSource();
        dynamicDataSource.setDefaultTargetDataSource(masterDataSource);
        dynamicDataSource.setTargetDataSources(targetDataSources);
        return dynamicDataSource;
    }
    
    private HikariDataSource createDataSource(String url, String username, String password) {
        HikariConfig config = new HikariConfig();
        config.setJdbcUrl(url);
        config.setUsername(username);
        config.setPassword(password);
        config.setDriverClassName("com.mysql.cj.jdbc.Driver");
        config.setMaximumPoolSize(20);
        config.setMinimumIdle(5);
        config.setConnectionTimeout(30000);
        return new HikariDataSource(config);
    }
}

// DynamicDataSource.java
public class DynamicDataSource extends AbstractRoutingDataSource {
    
    @Override
    protected Object determineCurrentLookupKey() {
        return DataSourceContextHolder.getDataSourceType();
    }
}

// DataSourceContextHolder.java
public class DataSourceContextHolder {
    private static final ThreadLocal<String> contextHolder = new ThreadLocal<>();
    
    public static void setDataSourceType(String dataSourceType) {
        contextHolder.set(dataSourceType);
    }
    
    public static String getDataSourceType() {
        return contextHolder.get();
    }
    
    public static void clearDataSourceType() {
        contextHolder.remove();
    }
}

// ReadOnlyAspect.java
@Aspect
@Component
public class ReadOnlyAspect {
    
    @Before("@annotation(org.springframework.web.bind.annotation.GetMapping)")
    public void setReadDataSource() {
        // 随机选择一个 Slave
        String slaveKey = "slave-" + (int) (Math.random() * 2);
        DataSourceContextHolder.setDataSourceType(slaveKey);
    }
    
    @Before("@annotation(org.springframework.web.bind.annotation.PostMapping) || " +
            "@annotation(org.springframework.web.bind.annotation.PutMapping) || " +
            "@annotation(org.springframework.web.bind.annotation.DeleteMapping)")
    public void setWriteDataSource() {
        DataSourceContextHolder.setDataSourceType("master");
    }
    
    @After("@annotation(org.springframework.web.bind.annotation.GetMapping)")
    public void clearDataSource() {
        DataSourceContextHolder.clearDataSourceType();
    }
}
```

#### 3.2.3 数据库迁移工具

**实施方案：使用 Flyway**

```xml
    <artifactId>flyway-core</artifactId>
</dependency>
<dependency>
    <groupId>org.flywaydb</groupId>
    <artifactId>flyway-mysql</artifactId>
</dependency>
```

**步骤2：创建迁移脚本**

```sql
-- V1__init_schema.sql
CREATE TABLE IF NOT EXISTS user (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    role VARCHAR(20) NOT NULL,
    created_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

CREATE TABLE IF NOT EXISTS product (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    price DECIMAL(10, 2) NOT NULL,
    status VARCHAR(20) NOT NULL DEFAULT 'ACTIVE',
    created_time DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_time DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- V2__add_user_email.sql
ALTER TABLE user ADD COLUMN email VARCHAR(100);

-- V3__create_index.sql
CREATE INDEX idx_product_status ON product(status);
CREATE INDEX idx_user_username ON user(username);
```

**步骤3：配置 Flyway**

```yaml
# application.yml
spring:
  jpa:
    open-in-view: true
    hibernate:
      ddl-auto: validate  # 改为 validate，仅验证不修改
    show-sql: true
  flyway:
    enabled: true
    baseline-on-migrate: true
    locations: classpath:db/migration
    encoding: UTF-8
    validate-on-migrate: true
```

**步骤4：创建基线（针对已有数据库）**

```bash
# 如果数据库已有数据，需要创建基线
mvn flyway:baseline
```

**步骤5：迁移流程**

```bash
# 开发新功能时，创建新的迁移脚本
# 命名规则：V{version}__{description}.sql
# 示例：V4__add_product_category.sql

# 执行迁移
mvn flyway:migrate

# 查看迁移状态
mvn flyway:info

# 回滚（需要配置 undo 脚本）
mvn flyway:undo
```

**注意事项：**
- 迁移脚本必须幂等（可重复执行）
- 禁止在迁移脚本中使用 DROP TABLE
- 重要迁移前备份数据库
- 迁移脚本必须经过测试环境验证

### 3.3 监控告警方案

#### 3.3.1 告警系统接入

**实施方案：使用钉钉/企业微信告警**

**步骤1：创建钉钉机器人**

1. 进入钉钉群设置 → 智能群助手 → 添加机器人
2. 选择"自定义"机器人
3. 获取 Webhook URL 和安全设置（关键词或签名）

**步骤2：实现告警服务**

```java
// AlertService.java
@Service
@Slf4j
public class AlertService {
    
    @Value("${alert.dingtalk.webhook}")
    private String dingtalkWebhook;
    
    @Value("${alert.dingtalk.secret}")
    private String dingtalkSecret;
    
    @Value("${alert.wechat.webhook:}")
    private String wechatWebhook;
    
    private final RestTemplate restTemplate;
    
    public AlertService(RestTemplate restTemplate) {
        this.restTemplate = restTemplate;
    }
    
    public void sendAlert(String title, String content, AlertLevel level) {
        // 1. 生成时间戳
        long timestamp = System.currentTimeMillis();
        
        // 2. 计算签名（钉钉）
        String sign = calculateSign(timestamp);
        
        // 3. 构建消息
        Map<String, Object> message = buildMessage(title, content, level, timestamp, sign);
        
        // 4. 发送告警
        sendDingtalkAlert(message);
        
        if (StringUtils.hasText(wechatWebhook)) {
            sendWechatAlert(title, content, level);
        }
    }
    
    private Map<String, Object> buildMessage(String title, String content, 
                                            AlertLevel level, long timestamp, String sign) {
        Map<String, Object> message = new HashMap<>();
        message.put("msgtype", "markdown");
        
        Map<String, String> markdown = new HashMap<>();
        markdown.put("title", title);
        
        String levelEmoji = switch (level) {
            case CRITICAL -> "🔴";
            case WARNING -> "🟡";
            case INFO -> "🔵";
        };
        
        String text = String.format("""
            ## %s %s
            
            **时间：** %s
            **级别：** %s
            
            **详情：**
            %s
            
            **建议操作：**
            %s
            """, 
            levelEmoji, title,
            LocalDateTime.now().format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss")),
            level.name(),
            content,
            getSuggestion(level)
        );
        
        markdown.put("text", text);
        message.put("markdown", markdown);
        
        // 添加签名参数
        message.put("timestamp", timestamp);
        message.put("sign", sign);
        
        return message;
    }
    
    private String calculateSign(long timestamp) {
        try {
            String stringToSign = timestamp + "\n" + dingtalkSecret;
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(dingtalkSecret.getBytes(StandardCharsets.UTF_8), "HmacSHA256"));
            byte[] signData = mac.doFinal(stringToSign.getBytes(StandardCharsets.UTF_8));
            return URLEncoder.encode(Base64.getEncoder().encodeToString(signData), StandardCharsets.UTF_8);
        } catch (Exception e) {
            log.error("Calculate sign failed", e);
            return "";
        }
    }
    
    private void sendDingtalkAlert(Map<String, Object> message) {
        try {
            HttpHeaders headers = new HttpHeaders();
            headers.setContentType(MediaType.APPLICATION_JSON);
            
            HttpEntity<Map<String, Object>> request = new HttpEntity<>(message, headers);
            String response = restTemplate.postForObject(dingtalkWebhook, request, String.class);
            
            if (response != null && response.contains("\"errcode\":0")) {
                log.info("Alert sent successfully");
            } else {
                log.warn("Alert send failed: {}", response);
            }
        } catch (Exception e) {
            log.error("Send dingtalk alert failed", e);
        }
    }
    
    private String getSuggestion(AlertLevel level) {
        return switch (level) {
            case CRITICAL -> "立即检查服务器状态，必要时回滚或切换备用服务";
            case WARNING -> "监控相关指标，准备应急预案";
            case INFO -> "持续观察，无需立即处理";
        };
    }
    
    public enum AlertLevel {
        CRITICAL, WARNING, INFO
    }
```

### 4.2 Refresh Token 机制

**问题：** JWT Token 24 小时过期，用户需要频繁登录。

**方案设计：**

```
登录
  ↓
返回 Access Token (15分钟) + Refresh Token (7天)
  ↓
前端存储两者
  ↓
Access Token 过期
  ↓
使用 Refresh Token 刷新 Access Token
  ↓

  ↓
```

```java
// RefreshTokenService.java
@Service
@Slf4j
public class RefreshTokenService {
    
    @Value("${jwt.refresh-expiration:604800000}")  // 7天
    private long refreshTokenDurationMs;
    
    @Autowired
    private RefreshTokenRepository refreshTokenRepository;
    
    @Autowired
    private UserRepository userRepository;
    
    public RefreshToken createRefreshToken(Long userId, String username) {
        // 1. 删除该用户旧的 Refresh Token
        refreshTokenRepository.deleteByUserId(userId);
        
        // 2. 生成新的 Refresh Token
        RefreshToken refreshToken = new RefreshToken();
        refreshToken.setToken(UUID.randomUUID().toString());
        refreshToken.setUserId(userId);
        refreshToken.setUsername(username);
        refreshToken.setExpiryDate(LocalDateTime.now().plusMillis(refreshTokenDurationMs));
        refreshToken.setRevoked(false);
        
        return refreshTokenRepository.save(refreshToken);
    }
    
    public RefreshToken verifyExpiration(RefreshToken token) {
        if (token.isRevoked()) {
            throw new TokenRefreshException("Refresh token was revoked");
        }
        
        if (token.getExpiryDate().isBefore(LocalDateTime.now())) {
            refreshTokenRepository.delete(token);
            throw new TokenRefreshException("Refresh token was expired");
        }
        
        return token;
    }
    
    public TokenRefreshResponse refreshToken(TokenRefreshRequest request) {
        String requestRefreshToken = request.getRefreshToken();
        
        return refreshTokenRepository.findByToken(requestRefreshToken)
            .map(this::verifyExpiration)
            .map(refreshToken -> {
                User user = userRepository.findById(refreshToken.getUserId())
                    .orElseThrow(() -> new TokenRefreshException("User not found"));
                
                // 生成新的 Access Token
                String accessToken = JwtUtil.generateToken(user);
                
                return TokenRefreshResponse.builder()
                    .accessToken(accessToken)
                    .refreshToken(requestRefreshToken)
                    .tokenType("Bearer")
                    .build();
            })
            .orElseThrow(() -> new TokenRefreshException("Refresh token not found"));
    }
    
    public void logoutUser(String username) {
        User user = userRepository.findByUsername(username)
            .orElseThrow(() -> new UsernameNotFoundException("User not found"));
        
        // 撤销所有 Refresh Token
        refreshTokenRepository.revokeAllByUserId(user.getId());
    }
}
```

```typescript
// src/api/auth.ts
import axios from 'axios'

interface TokenRefreshResponse {
  accessToken: string
  refreshToken: string
  tokenType: string
}

const refreshAccessToken = async (): Promise<string> => {
  const refreshToken = localStorage.getItem('refreshToken')
  if (!refreshToken) {
    throw new Error('No refresh token available')
  }

  const response = await axios.post<TokenRefreshResponse>('/api/auth/refresh-token', {
    refreshToken
  })

  const { accessToken, refreshToken: newRefreshToken } = response.data
  
  // 更新存储的 tokens
  localStorage.setItem('token', accessToken)
  localStorage.setItem('refreshToken', newRefreshToken)
  
  return accessToken
}

// Axios 拦截器
axios.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

let isRefreshing = false
let failedQueue: Array<{
  resolve: (value?: string) => void
  reject: (reason?: any) => void
}> = []

axios.interceptors.response.use(
  (response) => response,
  async (error) => {
    const originalRequest = error.config

    // Token 过期，尝试刷新
    if (error.response?.status === 401 && !originalRequest._retry) {
      if (isRefreshing) {
        // 如果正在刷新，将请求加入队列
        return new Promise((resolve, reject) => {
          failedQueue.push({ resolve, reject })
        }).then(token => {
          originalRequest.headers.Authorization = `Bearer ${token}`
          return axios(originalRequest)
        })
      }

      originalRequest._retry = true
      isRefreshing = true

      try {
        const newToken = await refreshAccessToken()
        
        // 重试队列中的请求
        failedQueue.forEach(({ resolve }) => resolve(newToken))
        failedQueue = []
        
        originalRequest.headers.Authorization = `Bearer ${newToken}`
        return axios(originalRequest)
      } catch (refreshError) {
        // 刷新失败，跳转登录页
        failedQueue.forEach(({ reject }) => reject(refreshError))
        failedQueue = []
        localStorage.removeItem('token')
        localStorage.removeItem('refreshToken')
        window.location.href = '/login'
        return Promise.reject(refreshError)
      } finally {
        isRefreshing = false
      }
    }

    return Promise.reject(error)
  }
)
```

```java
// RateLimiter.java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface RateLimiter {
    
    /**
     * 限流 key，支持 SpEL 表达式
     */
    String key() default "'default'";
    
    /**
     * 时间窗口（秒）
     */
    int time() default 60;
    
    /**
     * 时间窗口内允许的最大请求数
     */
    int count() default 100;
    
    /**
     * 限流策略
     */
    LimitType limitType() default LimitType.DEFAULT;
    
    /**
     * 提示信息
     */
    String message() default "访问过于频繁，请稍后再试";
    
    enum LimitType {
        DEFAULT,    // 默认策略，全局限流
        IP,         // 根据 IP 限流
        USER        // 根据用户 ID 限流
    }
}
```

**步骤3：实现限流切面**

```java
// RateLimiterAspect.java
@Aspect
@Component
@Slf4j
public class RateLimiterAspect {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    @Autowired
    private HttpServletRequest request;
    
    @Before("@annotation(rateLimiter)")
    public void doBefore(JoinPoint joinPoint, RateLimiter rateLimiter) {
        String key = buildKey(joinPoint, rateLimiter);
        long time = rateLimiter.time();
        long count = rateLimiter.count();
        
        String redisKey = "rate_limit:" + key;
        
        // 获取当前计数
        Long currentCount = redisTemplate.opsForValue().increment(redisKey);
        
        if (currentCount == null || currentCount == 1) {
            // 设置过期时间
            redisTemplate.expire(redisKey, time, TimeUnit.SECONDS);
        }
        
        if (currentCount != null && currentCount > count) {
            // 超过限制
            throw new RateLimitException(rateLimiter.message());
        }
        
        log.debug("Rate limit check: key={}, current={}, limit={}", key, currentCount, count);
    }
    
    private String buildKey(JoinPoint joinPoint, RateLimiter rateLimiter) {
        StringBuilder key = new StringBuilder();
        
        // 添加方法签名
        String className = joinPoint.getSignature().getDeclaringType().getSimpleName();
        String methodName = joinPoint.getSignature().getName();
        key.append(className).append(":").append(methodName);
        
        // 根据限流类型添加标识
        switch (rateLimiter.limitType()) {
            case IP:
                String ip = getClientIp();
                key.append(":").append(ip);
                break;
            case USER:
                String userId = getCurrentUserId();
                key.append(":").append(userId);
                break;
            case DEFAULT:
            default:
                // 使用配置的 key
                String customKey = parseSpEL(rateLimiter.key(), joinPoint);
                key.append(":").append(customKey);
                break;
        }
        
        return key.toString();
    }
    
    private String parseSpEL(String expression, JoinPoint joinPoint) {
        // 简化实现，实际应使用 SpEL 解析器
        return expression.replace("'", "");
    }
    
    private String getClientIp() {
        String ip = request.getHeader("X-Forwarded-For");
        if (ip == null || ip.isEmpty() || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getHeader("X-Real-IP");
        }
        if (ip == null || ip.isEmpty() || "unknown".equalsIgnoreCase(ip)) {
            ip = request.getRemoteAddr();
        }
        // 多个代理的情况，取第一个
        if (ip != null && ip.contains(",")) {
            ip = ip.split(",")[0].trim();
        }
        return ip;
    }
    
    private String getCurrentUserId() {
        // 从 SecurityContext 获取当前用户 ID
        Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
        if (authentication != null && authentication.isAuthenticated()) {
            return authentication.getName();
        }
        return "anonymous";
    }
}

        super(message);
    }
}
```

```java
// CachePenetrationProtection.java
@Component
public class CachePenetrationProtection {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    /**
     * 布隆过滤器预热
     */
    public void warmUpBloomFilter(Set<Long> productIds) {
        // 使用 Guava BloomFilter
        BloomFilter<Long> filter = BloomFilter.create(
            Funnels.longFunnel(),
            productIds.size(),
            0.01  // 误判率 1%
        );
        
        productIds.forEach(filter::put);
        
        // 将 BloomFilter 存入 Redis
        redisTemplate.opsForValue().set("bloom:product:ids", filter);
    }
    
    /**
     * 检查 ID 是否存在
     */
    public boolean exists(Long productId) {
        BloomFilter<Long> filter = (BloomFilter<Long>) 
            redisTemplate.opsForValue().get("bloom:product:ids");
        
        if (filter == null) {
            return true;  // 布隆过滤器未初始化，放行
        }
        
        return filter.mightContain(productId);
    }
}
```

#### 缓存击穿防护

```java
// CacheBreakdownProtection.java
@Component
public class CacheBreakdownProtection {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    /**
     * 使用互斥锁防止缓存击穿
     */
    public <T> T getWithLock(String key, Supplier<T> supplier, long expireTime) {
        // 1. 先尝试从缓存获取
        T value = (T) redisTemplate.opsForValue().get(key);
        if (value != null) {
            return value;
        }
        
        // 2. 获取分布式锁
        String lockKey = "lock:" + key;
        Boolean locked = redisTemplate.opsForValue().setIfAbsent(lockKey, "1", 10, TimeUnit.SECONDS);
        
        if (Boolean.TRUE.equals(locked)) {
            try {
                // 3. 获取锁成功，再次检查缓存（双重检查）
                value = (T) redisTemplate.opsForValue().get(key);
                if (value != null) {
                    return value;
                }
                
                // 4. 从数据库查询
                value = supplier.get();
                
                // 5. 写入缓存
                if (value != null) {
                    redisTemplate.opsForValue().set(key, value, expireTime, TimeUnit.SECONDS);
                }
                
                return value;
            } finally {
                // 6. 释放锁
                redisTemplate.delete(lockKey);
            }
        } else {
            // 7. 获取锁失败，等待并重试
            try {
                Thread.sleep(100);
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
            }
            return getWithLock(key, supplier, expireTime);
        }
    }
}
```

```java
// CacheAvalancheProtection.java
@Component
public class CacheAvalancheProtection {
    
    /**
     * 随机过期时间，防止缓存雪崩
     */
    public long getRandomExpireTime(long baseExpireTime) {
        // 基础过期时间的 80%-120% 随机
        double randomFactor = 0.8 + Math.random() * 0.4;
        return (long) (baseExpireTime * randomFactor);
    }
    
    /**
     * 写入缓存时使用随机过期时间
     */
    public void setWithRandomExpire(String key, Object value, long baseExpireTime) {
        long actualExpireTime = getRandomExpireTime(baseExpireTime);
        redisTemplate.opsForValue().set(key, value, actualExpireTime, TimeUnit.SECONDS);
    }
}
```

## 十、代码验证修订与精简建议

> 以下内容基于 2026-05-12 对源代码的实际验证，对方案中的错误、过度设计和遗漏进行修正。

### 10.1 代码示例错误修正

| 位置 | 错误 | 修正 |
|------|------|------|
| §3.2.1 Redis 哨兵配置 | `setPassword("123abc")` 写在 `RedisSentinelConfiguration` 上 | Spring Data Redis 2.x+ 中应使用 `sentinelConfig.setPassword("123abc")`，而非链式调用 |
| §3.2.2 读写分离 AOP | `@After` 清理 ThreadLocal，缺少 `@AfterThrowing` | 异常路径下 ThreadLocal 泄漏，需补充 `@AfterThrowing` 清理，或改用 `@Around` 统一处理 |
| §3.2.2 Slave 选择 | `Math.random() * 2` 硬编码 | 应使用轮询或加权策略，从配置中读取 slave 数量 |
| §3.2.3 Flyway 基线 | `mvn flyway:baseline` 未配置 Maven 插件 | 需先在 pom.xml 添加 `flyway-maven-plugin` 依赖和数据库连接配置 |
| §5.1 布隆过滤器 | `redisTemplate.opsForValue().set("bloom:product:ids", filter)` | Guava BloomFilter 不可序列化存入 Redis，应使用 RedisBloom 模块（`BF.ADD`/`BF.EXISTS` 命令） |
| §5.1 缓存击穿防护 | `getWithLock` 递归调用自身重试 | 高并发下递归可能导致栈溢出，应改为循环 + 最大重试次数限制 |
| §3.3.1 钉钉告警签名 | `timestamp` 和 `sign` 放在 message body 中 | 应作为 URL query 参数拼接在 webhook 后面：`?timestamp=xxx&sign=xxx` |

### 10.2 过度设计精简建议

> 本项目是**矿产品价格管理系统**，内部使用、用户量小（< 50 人）、QPS 极低（< 100）。以下方案对照此规模评估适配性。

| 方案 | 原方案建议 | 精简建议 | 理由 |
|------|-----------|---------|------|
| MySQL 主从 + 读写分离 | P0 实施 | ❌ 移除 | 内部系统 QPS 极低，单 MySQL 完全够用；需额外 2 台服务器，成本收益不成比例 |
| Redis 哨兵模式 | P0 实施 | ⚠️ 降为 P3 | 单 Redis 对内部系统足够，挂了重启即可；哨兵需 3+ 节点，运维成本高 |
| RabbitMQ 消息队列 | P2 实施 | ❌ 移除 | 当前无异步任务场景，引入 MQ 增加复杂度无实际收益 |
| Spring Cloud Gateway | P2 实施 | ❌ 移除 | 单体应用不需要网关，这是微服务架构的组件 |
| Skywalking APM | P1 实施 | ❌ 移除，替换为轻量方案 | 重量级方案需 Elasticsearch，对内部系统太重。改用 Spring Boot Actuator + 自定义健康检查 + 钉钉告警 |
| 微服务演进路线 | 长期目标 | ❌ 移除 | 内部管理系统不会发展到需要微服务的规模，保留单体架构即可 |
| 缓存穿透布隆过滤器 | P2 实施 | ❌ 移除 | 产品数据量小（百级），无穿透风险；且 Guava BloomFilter 不可直接存 Redis |
| 缓存击穿互斥锁 | P2 实施 | ⚠️ 降为 P3 | 内部系统并发极低，击穿概率微小 |

### 10.3 遗漏补充

| 遗漏项 | 严重程度 | 建议方案 | 预计工作量 |
|--------|---------|---------|-----------|
| `open-in-view: true` | 🔴 高 | 改为 `false`，使用 DTO 投影替代直接序列化 Entity | 1 天 |
| `useSSL=false` | ⚠️ 中 | 生产环境移除 `useSSL=false`，配置 MySQL SSL 证书 | 0.5 天 |
| `cache.type=simple` 未用 Redis | ⚠️ 中 | 改为 `cache.type=redis`，零成本激活 Redis 缓存 | 0.5 天 |
| docker-compose 与 yml 密码默认值不一致 | ⚠️ 中 | 统一为 `${DB_PASSWORD}` 无默认值，强制环境变量 | 0.5 天 |
| 前端 localStorage 存储 JWT 有 XSS 风险 | ⚠️ 中 | 改为 HttpOnly Cookie + CSRF Token 方案 | 2 天 |
