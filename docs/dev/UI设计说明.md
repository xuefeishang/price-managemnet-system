# 价格管理系统 UI 设计说明

## 设计概览

本次设计为价格管理系统创建了全新的专业简洁UI，具有以下特点：

### 核心设计理念
- **专业简洁**：清晰的视觉层次和简洁的设计语言
- **数据驱动**：突出价格信息的展示和管理功能
- **移动端优先**：完美适配手机屏幕
- **响应式设计**：支持不同尺寸设备

## 配色方案

### 主色调
- **青绿** (#0D6E6E)：主要操作按钮、重要信息强调、成功状态
- **橙色** (#E07B54)：价格更新、警告状态、次要操作

### 功能色
- **成功**：`#0D6E6E` (青绿)
- **警告**：`#E07B54` (橙色)
- **中性**：从 `#FAFAFA` (浅灰) 到 `#1A1A1A` (深灰) 的完整灰色系

### 中性色
- 页面背景：`#FAFAFA` (浅灰)
- 卡片背景：`#FFFFFF` (白色)
- 文字颜色：`#1A1A1A`、`#666666`、`#888888`
- 边框颜色：`#E5E5E5`

- 系统名称和副标题展示
- 用户名和密码输入框
- 快速登录选项（管理员/编辑者/查看者）

- 编辑功能入口

### 4. 产品编辑页面 (1zecz)

- 产品分类列表展示
- 分类名称、产品数量、状态
- 分类状态管理（启用/禁用）
- 编辑分类功能
- 添加新分类入口

### 6. 导入导出页面 (cc3JY)
- Excel文件导入功能
- 产品数据导出功能
- 操作指引说明
- 选择文件和导出按钮

### 7. 个人中心页面 (0R2jP)
- 用户信息展示（头像、姓名、邮箱、角色）
- 系统设置入口
- 帮助中心入口
- 关于系统入口
- 退出登录功能

### 8. 字典管理页面
- 按分类筛选字典项
- 字典项列表展示（分类、键、值、扩展值、排序、状态）
- 新增/编辑/删除字典项

- 字典分类标签页切换

### 9. 产地管理页面
- 产地列表展示（名称、编码、排序、状态）
- 新增/编辑/删除产地

### 10. 客户管理页面
- 客户列表展示（名称、编码、联系人、电话、状态）

- 启用/停用客户

- 左侧：部门树状结构（可折叠、拖拽调整层级）
- 右侧：部门详情编辑（编码、名称、类型、负责人、排序）

- 用户列表展示（头像+昵称(@用户名)一行显示）

- 操作按钮为图标按钮（分配角色/编辑/删除）

### 13. 日志管理页面（优化）
- 标签页紧凑按钮（日志列表/统计分析/月度报表/年度报表）
- 筛选栏紧凑单行（时间范围/用户名/操作类型/操作模块）
- 图表区域网格布局（趋势图、饼图、柱状图、排行图）
- 报表表格展示（日报明细、年度排行）

## 设计规范

### 字体系统
- **Newsreader**：用于标题和重要信息展示
- **JetBrains Mono**：用于数字、价格和代码相关内容
- **Inter**：用于正文和通用文字

### 字号层级（CSS变量规范）
使用 CSS 变量统一管理字体大小，便于全局调整和主题切换：

| 变量名 | 值 | 用途 |
|--------|-----|------|
| `--font-size-xs` | 0.75rem (12px) | 辅助信息、标签、小徽章 |
| `--font-size-sm` | 0.875rem (14px) | 表格内容、小标题、表单输入 |
| `--font-size-base` | 1rem (16px) | 正文、表头、主要文字 |
| `--font-size-lg` | 1.125rem (18px) | 小节标题、卡片标题 |
| `--font-size-xl` | 1.25rem (20px) | 页面副标题、导航栏标题 |
| `--font-size-2xl` | 1.5rem (24px) | 页面主标题 |
| `--font-size-3xl` | 1.875rem (30px) | 特大标题、价格数字 |

**预设方案（可通过样式设置页面切换）：**

| 方案 | xs | sm | base | lg | xl | 2xl | 3xl | 适用场景 | WCAG |
|------|-----|-----|------|-----|-----|------|------|----------|------|
| 紧凑 | 0.625rem | 0.75rem | 0.875rem | 1rem | 1.125rem | 1.25rem | 1.5rem | 数据密集型 | ❌ |
| 标准 | 0.75rem | 0.875rem | 1rem | 1.125rem | 1.25rem | 1.5rem | 1.875rem | 通用场景 | ❌ |
| 大字体 | 0.875rem | 1rem | 1.125rem | 1.25rem | 1.5rem | 1.75rem | 2rem | 演示/投影 | ✅ |
| 无障碍 | 0.875rem | 1rem | 1.125rem | 1.25rem | 1.5rem | 1.75rem | 2rem | WCAG 合规 | ✅ |

**UnoCSS 集成：**
- 使用 UnoCSS 原子化 CSS 引擎，与 Vant 组件库安全共存
- 字体大小通过 CSS 变量绑定，支持后台动态配置
- 语义化快捷方式：`text-caption`、`text-body`、`text-title`、`text-heading` 等

**使用示例：**
```css
.table-header { font-size: var(--font-size-base); }
.table-cell { font-size: var(--font-size-sm); }
.page-title { font-size: var(--font-size-2xl); }
```

### 间距系统
- 4px：紧密间距
- 8px：小间距
- 12px：中等间距
- 16px：标准间距
- 20px：大间距
- 32px：主要区域间距

## 响应式设计

### 设计尺寸
- **宽度**：402px（标准手机屏幕）
- **高度**：874px（包含安全区域）
- **内容边距**：24px

### 页面布局
所有页面遵循一致的布局模式：
- 顶部导航栏（56px高度）
- 内容区域（flex布局，自动填充剩余空间）
- 底部导航栏（64px高度，仅在首页可见）

## 交互设计

### 按钮状态
- **正常状态**：填充或描边颜色
- **悬停状态**：轻微缩放或颜色变化
- **点击状态**：按压效果，轻微下沉
- **禁用状态**：半透明效果

### 输入交互
- **聚焦状态**：边框高亮，背景色变化
- **错误状态**：红色边框和错误提示
- **成功状态**：绿色边框和成功提示
