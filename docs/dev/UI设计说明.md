# 价格管理系统 UI 设计说明

## 设计概览

本次设计为价格管理系统创建了全新的专业简洁UI，具有以下特点：

### 核心设计理念
- **专业简洁**：清晰的视觉层次和简洁的设计语言
- **数据驱动**：突出价格信息的展示和管理功能
- **移动端优先**：完美适配手机屏幕
- **响应式设计**：支持不同尺寸设备

## 配色方案

### 主色调
- **青绿** (#0D6E6E)：主要操作按钮、重要信息强调、成功状态
- **橙色** (#E07B54)：价格更新、警告状态、次要操作

### 功能色
- **成功**：`#0D6E6E` (青绿)
- **警告**：`#E07B54` (橙色)
- **中性**：从 `#FAFAFA` (浅灰) 到 `#1A1A1A` (深灰) 的完整灰色系

### 中性色
- 页面背景：`#FAFAFA` (浅灰)
- 卡片背景：`#FFFFFF` (白色)
- 文字颜色：`#1A1A1A`、`#666666`、`#888888`
- 边框颜色：`#E5E5E5`

### 2. 首页/驾驶舱 (PxPQB)
- 经营摘要区（产品总数、今日更新、涨跌统计）
- 核心指标区（重点产品大卡片，36px价格数字，涨跌标签）
- “趋势分析”在样式设置中更名为“重点走势”，不再展示大折线图；该区块由 `trend_chart` 控制显隐，内容动态跟随当前重点关注指标，最多展示 4 个小折线图卡片，并支持 7日/30日/90日切换
- 产品列表区在 PC 端升级为分页表格工作台，支持搜索、分类筛选、分页、排序、行选中联动主价格曲线；样式设置可切换表格、卡片或自动模式，表格/卡片模式在全尺寸、中间尺寸、H5 均严格遵循配置，自动模式为全尺寸和中间尺寸表格、H5 卡片；中间尺寸和 H5 的卡片模式采用价格查询页产品列表的信息结构，展示产品名、产地、规格、当日售价、昨日售价和较昨日；H5 表格模式采用价格查询页同款 4 列结构“产品名称、当日售价、昨日售价、较昨日”，仅允许表格容器内部横向滚动，页面本身不产生横向滚动
- PC 首页产品列表工具栏中的分类筛选采用传统下拉菜单，便于快速选择单一分类并减少悬浮面板对表格区域的遮挡；切换分类、搜索、分页条数和上一页/下一页时采用后台静默更新，保留当前表格直到新结果返回，避免整块列表出现刷新感
- 首页产品列表工具栏与下方表格/卡片列表之间保留独立留白，避免筛选控件与列表内容紧贴
- PC 首页内容区宽度跟随主布局可用宽度铺满，不再额外设置居中最大宽度；页面边距由全局 Layout 主内容区统一控制，避免双层左右留白
- 首页首行经营摘要采用产品总数、当日更新、更新率、覆盖品类四项纯指标卡，不展示小字说明，数字为视觉焦点；其中当日更新随首页所选日期变化，统计该日期已有报价的产品数，更新率用于中性表达当日价格维护覆盖情况；价格曲线使用独立主图表面板展示当前产品价格、涨跌、统计值和趋势图
- 首页 ECharts 图表在浏览器最小化或页面隐藏时必须暂停自动 resize，避免最小化窗口尺寸触发图表自适应和窗口恢复
- 首页核心区左侧重点产品价格固定展示最多 4 个产品，采用 2×2 价格速览卡；全尺寸下右侧价格曲线负责趋势分析，重点产品卡不放置 Mini 折线图；中间尺寸下隐藏所有大折线图，重点产品卡右半侧展示 Mini 折线图以保留走势信息并节省空间
- 首页产品表列采用“产品名称、类别、规格、最新价格、单位、较昨日、走势图、更新时间”组合；产品产地在产品名右侧以胶囊展示，产品名下方不展示编码，最新价格不再额外展示币种符号子行，规格与单位分列展示且单位紧邻最新价格右侧，类别列和单位列保持紧凑左移以提升横向密度；“较昨日”与价格维护页价格变化列保持同一差值计算口径，并在差值后以括号补充比例；规格列长文本默认省略，悬停时使用走马灯展示完整内容；走势图左对齐，取消独立操作列，更新时间按完整年月日时分秒展示最后一次更新时间
- 产品列表、重点关注指标、重点走势按分类 `sortOrder` + 产品 `sortOrder` 稳定排序；管理员可在样式设置的“首页排序”页签调整分类顺序和分类内产品顺序
- 首页渲染分类顺序时以 `/api/categories?status=ACTIVE` 返回的最新分类 `sortOrder` 为准，产品实体中嵌套的分类排序仅作为兜底，避免排序保存后首页仍读取旧嵌套数据
- 首页产品信息统一采用“名称 + 产地胶囊 → 规格 → 价格/走势”的层级；产地在名称右侧展示，来自 `origin` 字典，只有产品已配置真实产地时展示，不显示“未设置”等占位文案
- 首页核心区采用“重点产品价格卡 + 主价格曲线”双栏构图，重点产品卡点击后更新主曲线和产品表格高亮状态
- 首页默认展示昨日价格，适配矿产品行情通常在次日补录和复盘的业务节奏；如切换到当天日期，则价格变化口径与价格维护页保持一致
- 首页日期选择器支持点击日期文本/日期输入区域直接唤起系统日期控件，避免仅点击日历图标才可打开
- 浏览器页签图标必须随样式设置中的 Logo 动态更新，优先使用导航栏 Logo，其次使用默认 Logo，不再展示框架默认图标；页签图标使用 64×64 专用画布按居中裁剪方式放大生成，避免原 Logo 在浏览器标签中过小
- 系统路由需屏蔽 Vue Router 在 `document.visibilitychange` 中保存滚动位置的默认监听，避免部分 Edge/Chrome 环境在窗口最小化进入 hidden 状态时因 `history.replaceState` 触发浏览器窗口立即恢复
- 价格预警区（单日涨跌>5%、连续涨跌预警），无预警时保留空状态提示，避免误判功能消失
- 首页区块显隐和排序由样式设置中的 `home_widget` 配置驱动，兼容历史 `price_alerts` 并统一为 `risk_alerts`
- 首页三档响应式规则：全尺寸摘要展示 4 项并展示重点产品价格 + 大价格曲线；中间尺寸按 Home 内容容器宽度识别，摘要只展示“产品总数、当日更新”2 项，重点产品卡显示 Mini 折线图，不展示 `HomePriceCurvePanel` 或独立 `TrendAnalysisChart` 大图；H5 不展示经营摘要和重点走势，重点关注指标在 1024px 以下统一采用 2×2 紧凑卡片，避免 H5 与中间尺寸之间出现额外状态，产品列表模式仍严格遵循样式设置配置
- 迷你面积图（渐变填充，趋势可视化）
- 深矿蓝主色(#165DFF)、红涨绿跌配色

### 4. 产品编辑页面 (1zecz)
- 完整的产品信息编辑表单
- 产品名称、编码、分类、规格、状态
- 价格信息编辑（原价、现价、成本价、生效日期）
- 备注文本区域
- 保存操作按钮
- 价格维护页进入时默认展示昨日日期，与首页默认行情日期保持一致，便于次日补录和复盘
- 价格维护页日期切换必须按本地日期增减并保持控件区固定宽度；左右切换按钮与日期输入框不使用外层装饰容器，按钮采用固定尺寸和稳定按压态，点击时不得出现布局抖动
- 价格维护页列表样式与首页产品列表工作台保持一致：PC 端采用自适应分页表格且不显示横向滑块，移动端采用价格卡片；支持产品名称搜索、产品类别筛选、上一页/下一页翻页和拖拽手柄调整当前列表产品顺序，排序列不显示文字表头；拖起时展示产品浮层预览，拖到两行/两卡之间时用顶部或底部插入线标识落点；拖拽落位后立即通过 `/api/products/batch-sort` 同步产品 `sortOrder`，并刷新 Home 页面排序
- 价格维护页保留当日售价录入与批量保存能力，同时展示预算价格、昨日售价、价格变化和月均价，保存时仅提交实际发生变化的价格行
- 价格维护页产品行与移动端卡片读取样式设置中的分类视觉配置，类别圆点、产地胶囊、卡片边框和浅底色需与首页保持同源
- 价格维护页的昨日售价、价格变化、月均价必须按产品币种显示货币符号；价格变化保留涨跌正负号，格式为 `+¥1.00` / `-¥1.00`
- 价格查询页位于产品管理下，视觉参考价格维护/产品列表工作台，但保持只读语义：左侧为产品价格列表，右侧为当前选中产品趋势、价格统计和变化说明；工具栏左侧为搜索、分类、每页条数，主操作“导出数据”贴右展示，窄屏自动换行
- 价格查询页表格列采用“产品名称、当日售价、昨日售价、较昨日”；取消独立类别列、产地列、规格列、单位列和币种列，产地以字典名称胶囊融入产品名称后方，规格作为产品名称下方副信息展示；产品名称、分类圆点、产地胶囊和当前价读取 `style-settings?section=category` 的分类视觉配置并与 Home 页面保持一致，“较昨日”仅展示价格差值，涨跌色读取样式设置中的色彩配置
- 价格查询页默认展示昨日日期，行点击刷新右侧趋势；导出按钮固定尺寸并带 loading 状态，避免重复点击和布局抖动；右侧折线图采用与 Home 价格曲线一致的柔和面积线视觉，顶部同一行左侧展示产品名称、产地和规格，右侧展示 7日/30日/90日/年度切换，不重复展示查询日期，主线色和面积色读取当前产品分类视觉配置，预算参考色读取样式设置
- 价格查询页 PC 端高度必须随浏览器视口自适应：左右面板同高，表格区和折线图区在可用高度内弹性伸缩；产品列表默认使用“自适应条数/页”，并按表格真实可用高度自动重算展示条数，避免固定高度导致页面显得死板
- 价格查询页分页超过可直接展示范围时必须显示首页、当前页附近页码、末页和省略号，不能静默隐藏后续页码
- 价格查询页窄屏下改为上下布局，表格横向滚动而不是挤压列宽；价格字段无数据时展示 `--`，趋势为空时保留时间范围切换并显示空状态

### 8. 字典管理页面
- PC 端采用“顶部领域切换 + 分类胶囊导航 + 表格/说明两栏”的工作台布局，一级领域横向切换，二级分类自动换行并支持展开/收起，避免左侧导航长期占用表格宽度

- 按分类维护字典项，同一时刻聚焦一个分类，降低误改风险
- 字典项列表展示（分类、键、值、扩展值、排序、状态）
- 新增/编辑/删除字典项
- 启用/停用字典项
- 字典分类导航切换，二级分类项只展示中文名称和数量，编码保留在当前分类详情区展示，并持续保留所属领域上下文
- 暂未补充分类元数据的字典项不单独显示“未登记分类”分组，统一并入业务字典导航展示，避免暴露技术治理状态
- 表格操作列使用与用户管理一致的 28px 图标按钮，编辑为铅笔图标，删除为垃圾桶图标
- 分类说明展示用途、使用页面、Key/显示值/扩展值填写规则和风险提示
- 效果展示优先使用当前分类真实启用字典项，支持下拉选项、状态色、图标、JSON和只读配置预览
- "显示系统配置"开关（仅ADMIN可见，显示受保护分类）
- 受保护分类只读展示，提供跳转样式设置或分类视觉配置入口
- extraValue智能渲染（颜色色块、JSON格式化+复制、图标预览）

### 14. 样式设置页面（响应式配置工作台）
- **PC布局**：顶部配置域Tab + 两栏工作台（配置区 | 右侧预览区360px），取消页面内部左侧导航，避免与系统左侧菜单重复占位；所有右侧实时预览无外层卡片框，不设置独立滚动条，并随页面整体滚动保持在可视范围内
- **移动端布局**：横向滚动配置域Tab + 配置区 + 预览抽屉
- **三层状态模型**：serverConfig（服务端基线）/ draftConfig（当前编辑）/ appliedConfig（已应用CSS）
- **草稿保存模式**：页面内选择与微调只更新草稿，顶部“保存配置”是唯一正式生效入口
- **9个配置域**：
  - 总览：当前方案摘要、保存状态、健康检查；方案显示名优先使用接口预设缓存
  - 品牌：系统名称与登录页副标题同排维护，文本输入实时进入草稿；Logo上传、Logo尺寸、副标题样式
  - 色彩：色彩方案切换、高级涨跌色微调默认展开；图表色板在右侧预览区展示，颜色输入通过 `#RGB` / `#RRGGBB` 校验后进入草稿
  - 排版：字号预设切换、字体族配置、字号预览
  - 布局：布局方案切换、页面密度、卡片样式
  - 首页体验：产品卡片列数、重点产品数量（1-4）、产品列表模式、产品表每页条数；不再保留首页布局模式、移动端卡片列数、重点走势/预警区独立开关
  - 首页产品表：支持产品列表模式和每页条数配置，配置通过 `home_layout` 保存并随顶部“保存配置”统一生效；右侧预览同步展示表格/卡片模式与分页大小
  - 首页排序：首页组件显隐与上下顺序、产品列表分类顺序、分类内产品顺序；组件显隐统一由 `home_widget.enabled` 控制，桌面端采用分类栏 + 当前分类产品栏，移动端采用上下结构，随顶部“保存配置”统一生效
  - 演示设置预览：按首页真实结构展示经营摘要、重点产品价格 + 主价格曲线、产品列表和风险预警；产品卡片骨架同步展示产地信息位置，产地仅作为有数据时出现的辅助信息

- **状态栏**：保存状态实时显示（正在保存/已保存/保存失败）
- **顶部操作**：仅保留“保存配置”，版本恢复通过配置域 Tab 进入
- **配置域状态同步**：通过 `section` 查询参数恢复当前配置域，切换配置域不触发未保存离开确认

### 15. 系统导航布局
- **左侧菜单**：展示当前用户可见的完整菜单树，支持一级、二级、三级、四级及更深层级
- **顶部上下文导航**：只展示当前二级分支下的三级Tab，不重复展示二级菜单
- **四级菜单**：收纳在对应三级Tab的点击下拉中
- **菜单点击规则**：带 `path` 的菜单项点击优先导航；无路径分组点击只展开/收起，不自动跳转；没有实际路由上下文时顶部导航隐藏
- **菜单响应反馈**：左侧菜单点击后立即展示目标菜单选中态，目标页面数据加载较慢时也不得让导航按钮呈现无响应状态
- **菜单字号**：二级及以下菜单、顶部上下文导航和下拉菜单统一使用 `--font-size-sm`，确保大字体/特大字体预设下导航文本同步放大

## 响应式设计

### 设计尺寸
- **宽度**：402px（标准手机屏幕）
- **高度**：874px（包含安全区域）
- **内容边距**：24px

### 页面布局
所有页面遵循一致的布局模式：
- 顶部导航栏（56px高度）
- 内容区域（flex布局，自动填充剩余空间）
- 底部导航栏（64px高度，仅在首页可见）

### 自适应列表与表格
- PC 端列表/表格工作台默认采用弹性高度：页面、面板、表格容器逐层 `flex` 填充可用空间，避免用固定高度造成浏览器尺寸变化时版式僵硬
- 带分页的数据表默认提供“自适应条数/页”：根据表格容器真实可用高度、表头高度和实际行高计算每页条数，并将计算结果同步到后端分页 `size`
- 自适应不是只改变分页下拉文案；当当前展示 5 条但表格区域还能容纳更多行且仍有数据时，应自动增加本页展示条数并重新拉取数据，减少空白区域
- 自适应计算需在 DOM 渲染后执行，并监听窗口或容器尺寸变化；搜索、筛选、切换分页模式后应重新校准
- 移动端或窄屏下允许切换为卡片、上下布局或内部纵向滚动；横向滚动只用于确实无法压缩的表格字段，不作为 PC 端默认方案

### 分页按钮
- 分页总页数较少时完整展示所有页码，避免用户误以为只有部分页面
- 分页总页数超过可直接展示范围时，必须展示首页、当前页附近页码、末页，并用 `...` 明确提示中间还有未展示页，不能只显示前三页或静默截断
- 分页控件应同时保留上一页/下一页、总条数和跳页能力；省略号只做提示，不作为跳页替代
- 当前页必须有明确高亮，首页/末页/上一页/下一页的禁用态要与真实页码同步

## 交互设计

### 按钮状态
- **正常状态**：填充或描边颜色
- **悬停状态**：轻微缩放或颜色变化
- **点击状态**：按压效果，轻微下沉
- **禁用状态**：半透明效果

### 输入交互
- **聚焦状态**：边框高亮，背景色变化
- **错误状态**：红色边框和错误提示
- **成功状态**：绿色边框和成功提示

### 分类视觉预设

分类视觉用于首页产品卡片的类别识别，不替代全局主题色。分类色仅作用于 icon、产品名强调、弱边框、浅色背景和迷你趋势图线条；涨跌文字仍使用全局涨跌色。

**方案层级：**

| 层级 | 数量 | 作用 |
|------|------|------|
| 整体组合方案 | 5套内置 + 1套我的组合 | 按当前分类批量匹配 icon、主色、浅底、边框和趋势图色 |
| 分组方案库 | 5组 × 10套 | 用户可在矿石金属、能源活跃、贵金指数、钢铁合金、化工循环中单独选择 |
| 底层推荐逻辑 | 不独立展示 | 用于新分类默认方案、组合 fallback 和默认分组定位 |
| 微调助手 | 单分类 | 通过背景浓度、边框明显度、光晕强度、趋势线强度做轻量调整 |

**组合方案：**

| 组合 | 视觉气质 | 适用场景 |
|------|----------|----------|
| 稳健矿业 | 清爽稳重 | 默认推荐，适合大多数矿产品价格系统 |
| 活跃交易 | 活跃清晰 | 高频报价、交易属性强的业务 |
| 贵金聚焦 | 价值聚焦 | 贵金属、指数、高价值产品 |
| 工业合金 | 工业结构 | 钢铁、合金、稀有金属 |
| 化工循环 | 洁净理性 | 化工辅料、酸类、回收材料 |
| 我的组合 | 自定义 | 仅允许 1 组历史兼容映射；当前界面不提供独立创建/更新入口 |

**分组方案库：**

| 分组 | 数量 | 适用场景 |
|------|------|----------|
| 矿石金属 | 10套 | 铝矿、铜矿、铅锌矿、铁矿、普通矿石 |
| 能源活跃 | 10套 | 电铜、新能源材料、活跃交易品 |
| 贵金指数 | 10套 | 金、银、贵金属、指数、波动提醒 |
| 钢铁合金 | 10套 | 钢坯、钢材、合金、稀土、钼钨镍 |
| 化工循环 | 10套 | 硫酸、化工辅料、试剂、废钢、回收料 |

**约束：**

- 分类列表以产品分类主数据为源，视觉配置仅作为附属样式。
- 预设保存为 token 快照，包含 `presetId` 与 `presetVersion`。
- 组合方案点击后直接更新未配置分类的草稿，右侧预览同步展示，点击顶部“保存配置”才影响首页。
- “我的组合”全系统只保留 1 组，保存到 `category_visual_custom_combo`；当前界面不提供独立保存按钮，避免绕过统一草稿保存模型。
- 文本对比度需满足 4.5:1，主色在白底上至少 3:1。
- 微调助手默认折叠，仅管理员可见；专家颜色入口作为二级折叠，保存前执行色彩校验。
